# 📚 Materiais de Apoio - Monitorias

Bem-vindo(a) ao repositório de materiais de apoio! Este espaço foi criado para centralizar e compartilhar recursos que auxiliem os alunos no acompanhamento e na fixação dos conteúdos das disciplinas com monitoria.

---

## 🎯 Objetivo

Aqui você encontrará conteúdos complementares elaborados e organizados pelos monitores, incluindo:
- **Listas de Exercícios** para prática do conteúdo.
- **Slides de Aulas/Revisões** com explicações resumidas e focadas.
- **Artigos e Leituras Recomendadas** para aprofundamento teórico.

---

## 📂 Estrutura das Disciplinas

O repositório está organizado em pastas dedicadas para cada disciplina. Navegue diretamente para a pasta correspondente à sua aula:

```text
.
├── metodos-avancados-de-programacao/   # MAP: Tópicos avançados, padrões e arquitetura
├── linguagem-de-programacao-2/          # LP2: Conceitos de Orientação a Objetos e linguagem Java
└── laboratorio-de-programacao-2/        # LAB2: Prática, projetos e testes automatizados
```

---

### 1. Métodos Avançados de Programação
